# OmnissiahCore

Python and FastAPI backend for The Kaban Project, a Warhammer 40,000 lore app. It uses hybrid search and evidence-driven retries to answer questions and reconstruct scenes with source references in [TheForge](https://github.com/Onoduchiagozie/TheForge), the Blazor frontend.
